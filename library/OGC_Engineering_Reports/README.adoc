# Space Standards DWG

The activities performed in the Space Domain are not much different from those performed in the Terrestrial Domain. The big difference is the framework of space and time within which those activities are performed.

The OGC/ISO Standards for spatial and temporal geometry are largly agnostic as to where they are applied. By extending the scope of these Standards to include non-terrestrial geometries, we should also extend the scope of existing spatiotemporal applications.

This question was investigated in OGC Testbeds 18 and 19. The following Engineering Reports capture the results of those efforts.

The key differences between terrestrial geospatial and non-terrestrial geospatial is in the reference frames used and the conversions between those reference frames. The Reference Frame Transformation Engineeing Report describes how existing OGC/ISO standards for geometry can be extended to support non-terrestrial applications.
